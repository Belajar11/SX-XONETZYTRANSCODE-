Pulse memakai FFmpeg WebAssembly dari CDN saat pertama kali dijalankan, jadi koneksi internet diperlukan. Proses video besar/4K dapat lambat atau kehabisan memori pada HP.
Catatan
  • Pulse memproses file di browser; file sumber tidak diunggah.
  • Forge dan Nova memerlukan backend server asli yang tidak disertakan dalam file ini.
  • Output MP4 menggunakan H.264/AAC bila codec tersedia pada build FFmpeg yang dimuat.
  • Hasil akhir tetap bergantung pada kualitas video sumber dan kompresi platform tujuan.
